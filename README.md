# Dreigingsbeeld

Verzamelt elk uur openbare informatie over cyberdreigingen en publiceert die als JSON via GitHub Pages.

## Bronnen

- CISA Known Exploited Vulnerabilities
- NCSC-NL beveiligingsadviezen (CSAF)
- NVD, met EUVD (ENISA) als terugval
- EPSS scores (FIRST)
- datalekt.nl incidenten
- ransomware.live (Nederland)
- RSS: Security.nl, Tweakers, Techzine, Computable, AG Connect, Cybernews, BleepingComputer
- GDELT: incidenten, securitynieuws en digitale soevereiniteit

## Uitvoer

- `dreigingsbeeld.json`: actuele signalen
- `history.json`: dagelijkse tellingen voor trends

Er vindt geen filtering of weging plaats; dat gebeurt bij de afnemer.
